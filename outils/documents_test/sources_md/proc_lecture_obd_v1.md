# Principe

À la réception, le technicien lit les codes défaut OBD-II du véhicule avec un lecteur branché sur la prise de diagnostic à 16 broches.

# Procédure (version 1, janvier 2025)

1. Contact coupé, brancher le lecteur sur la prise de diagnostic.
2. Mettre le contact.
3. Lire les codes présents.
4. **Effacer tous les codes dès la réception**, puis faire un court essai routier.
5. Relire les codes : seuls ceux qui réapparaissent sont traités.
6. Noter les codes réapparus sur la fiche d'intervention.

> INFO: cette méthode permet de ne traiter que les défauts actifs.
